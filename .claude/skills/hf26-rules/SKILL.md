# HF26 Week 1 — "Touch Grass" (source: https://dev.to/challenges/hacktoberfest-week1-2026-10-05, read 2026-10-07)

## Prompt
Build something with **open-source AI at its core** (open-weight model, open-source agent harness/framework, local inference — or all three). The open pieces must be what makes it work.
Theme: gets people **off the screen and into the world** (hiking, gardening, birding, run clubs, fall foliage). Best builds make the screen the shortest part of the experience.
Post must explain **why open innovation matters** for the build (offline, data stays local, fine-tune/swap models, zero cost, where open beat closed).
Bonus: take it outside, use it, tell how it went.

## Dates
Start 2026-10-05 · **Due 2026-10-11 23:59 PDT** · Winners week of 2026-10-12. 18+ only.

## Judging (weight order)
1. Writing Quality (heaviest) 2. Relevance to prompt & theme 3. Creativity 4. Technical execution 5. Use of partner tech (optional)

## Prizes
Overall: $250 + DEV++ + badge. Completion badge for every valid entry.
Featured partners ($200 each): Render, TabPFN, Tinker, Arduino (UNO Q), DigitalOcean, **Gemma**.
Partner ($100 each): Backboard, ElevenLabs, Entire, GitHub Copilot, Mastra, MongoDB Atlas, Sentry Agent Tracing, SerpApi, Temporal, Tiger Data.
Partner credits: hacktoberfest.com/my/promos (Tinker, Render, Backboard, ElevenLabs) — user claims themselves.

## Submission
Publish a DEV post using the official template (adds tags `devchallenge, hf26challenge`). Sections:
What I Built · Demo · Code · How I Built It · Why Does Open Innovation Matter? · My Agent Session (optional; DevRelay embed via `agent_session` tag or link) · Prize Categories.
Team: one member publishes and lists teammates' DEV usernames in body.
Must be a new project (not an old one, not a PR to an existing repo) — check FAQ if in doubt.
